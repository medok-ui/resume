# Интерактивное резюме | Interactive Resume

Интерактивное веб-резюме фронтенд-разработчика, созданное на чистом JavaScript (ES6+) с использованием модульной архитектуры и CSS-переменных.

## Особенности проекта

- **Переключение тем (Тёмная / Светлая):** Мгновенная смена цветовой схемы с сохранением выбора пользователя в `localStorage`.
- **Динамическая фильтрация навыков:** Интерактивные кнопки-фильтры по категориям (Frontend, Tools) на основе классов JavaScript.
- **Адаптивный дизайн:** Корректная вёрстка под любые экраны — от мобильных телефонов до широких мониторов.
- **Модульная структура:** Разделение логики на независимые компоненты (`Main.js`, `Theme.js`).

## Технологии

- **HTML5** (семантическая и доступная разметка)
- **CSS3** (CSS Custom Properties, Flexbox, Grid, медиа-запросы)
- **JavaScript (ES6+)** (Классы, модули, DOM API, LocalStorage)
